# ADS401 Group J Web Report

This repository hosts the single-page report for the LibAI evaluation project.

## Report status

- Survey: 107 eligible XJTLU postgraduate responses from 124 raw submissions.
- Task comparison: 20 participants, below the original 24-30 target; 120 task answers were scored.
- The task analysis lacks comparable timing data. Treat comparisons as exploratory and do not rank system speed.
- The earlier n=94 survey summary has been superseded by the current cleaned n=107 file.

## Files

- `ADS401_GroupJ_Report.html` - the hosted report.
- `assets/style.css` and `assets/app.js` - page styles and navigation behaviour.
- `assets/analysis-charts/` - aggregate survey charts for n=107.
- `assets/experiment-charts/` - reported aggregate task-study charts.
- `assets/experiment-protocol.pdf` - the original 8 November 2026 pre-experiment protocol; it is not an experiment-results report.

Participant-level data, raw survey exports, recordings and trial-level scoring files are not stored in this repository.
