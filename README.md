## ADS401 Group J project

This project evaluates XJTLU postgraduate students' use, perceptions and improvement priorities for the Library AI tool LibAI.

[Read the full web report](https://mirroringmohe.github.io/ADS_GroupJ_WR.github.io/ADS401_GroupJ_Report.html)

### Current progress

- The questionnaire is complete, with 94 eligible responses in the cleaned survey analysis.
- The site reports aggregate survey results on AI use, LibAI task help, usability, barriers and improvement priorities.
- Four core analysis charts are shown directly, with the remaining survey charts available in an expandable gallery.
- The completed 3 × 2 within-subjects experiment compares LibAI, DeepSeek and GPT-6 Luna. It includes 120 answer-quality ratings from 20 participants and satisfaction and expectation ratings from 15.
- The downloadable statistical report and experiment protocol are included in `assets/`.
